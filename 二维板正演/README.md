# 二维板重力与磁力正演

经典有限延深二维倾斜板模型的重力与磁力正演 MATLAB 实现。

## 功能简介

程序构建二维倾斜板模型，并沿地表观测线计算：

- 重力异常；
- 磁异常的水平分量 \(\Delta X\) 与垂直分量 \(\Delta Z\)；
- 沿磁化方向投影的总场异常 \(\Delta T\)。

模型几何与默认参数对应《二维板正演实验》课程内容。

## 默认模型参数

| 参数 | 含义 | 默认值 |
|---|---|---:|
| \(x_0, z_0\) | 板中心坐标 | 1000 m，1000 m |
| \(2b\) | 板宽 | 400 m |
| \(2L\) | 板长 | 800 m |
| \(\alpha\) | 板倾角 | 90° |
| \(i\) | 磁化倾角 | 90° |
| \(M\) | 磁化强度 | 2000 |
| \(\sigma\) | 密度差 | 2.67 g/cm³ |
| \(x\) | 地表观测点 | 0:20:2000 m |

将 `alpha_deg` 和 `i_deg` 改为 `45`，即可计算课件中的另一组倾角参数。

## 运行方法

在 MATLAB 中运行：

```matlab
two_dimensional_plate_forward
```

程序不依赖第三方工具箱，会依次绘制三幅图：

1. 二维倾斜板模型；
2. 重力异常曲线，单位为 mGal；
3. 磁异常曲线，包括 \(\Delta X\)、\(\Delta Z\) 与 \(\Delta T\)。

## 说明

- 重力异常采用收敛的二维体元积分计算，可适用于任意板倾角。
- 磁异常采用课程课件给出的有限延深二维板解析表达式计算。
- 当前磁异常结果与输入磁化强度 \(M\) 同单位。若 \(M\) 的单位为 A/m，可将结果转换为 nT：

```matlab
mu0 = 4*pi*1e-7;
dT_nT = mu0 * dT * 1e9;
```
